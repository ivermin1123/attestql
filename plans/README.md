# plans/

Dated records of work that was done. Nothing here is current documentation: the evergreen
statements live in `README.md` and under `docs/`, and a document in this directory is true of the
day it carries rather than kept true afterwards. Three kinds of thing are in it.

**Plan directories** (`plans/<date>-<slug>/`) hold a `plan.md` and a file per phase: what was
going to be built, in what order, and what each phase had to satisfy. They are the intent.

**Reports** (`plans/reports/`) are the outcome: a measurement, a spike, a piece of research, a
review, or a phase's own report, each naming what it ran, over which files, and what came back.
Many carry the run output beside them, which is where the numbers in `README.md` were read from.

**Journals** (`plans/journals/`) are session records, in order, including what went wrong.

Which of these a claim rests on is not decided by reading them.
[docs/claims-register.md](../docs/claims-register.md) is where a claim is owned: every claim this
project makes, the artifact that owns it, and who verified it.
